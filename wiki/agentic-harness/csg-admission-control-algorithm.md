# CSG Admission Control Algorithm

The CSG Admission Control Algorithm is the runtime verification mechanism within the Constraint State Governance framework that determines if an agent's proposed action is safe to execute.

## Evaluation Predicates

When an agent proposes a critical action, the algorithm checks multiple predicates against the current cryptographic state digest:
- **FRESH**: Ensures the constraint state and delegation tokens are not stale.
- **CAPOK**: Verifies the agent has the appropriate delegated capability.
- **SCOPEOK**: Confirms the action's semantic effect falls within the permitted scope.
- **FLOWOK**: Checks labels and budgets to prevent illegal information flow.
- **EVIDENCEOK**: Validates that proper rationale and context exist for the audit log.

## Tamper-Evident Hashing

If all checks pass, the action is realized, and a new audit root is generated by hashing the previous root with the current event (action, capability, evidence, decision, reason). This ensures that any realized trajectory is cryptographically bound to the conditions that authorized it.
