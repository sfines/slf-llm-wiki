# Continual Learning in Agents

**Continual Learning** refers to the ability of an [Autonomous Agent](autonomous-agents.md) to accumulate knowledge and improve its performance over time based on its own experiences and feedback.

## Mechanisms for Agents
- **[Persistent Note-Taking](../confucius/confucius-persistent-notes.md):** Saving insights to external storage for future retrieval.
- **[Agentic Context Engineering (ACE)](../agentic-harness/agentic-context-engineering.md):** Evolving system prompts and playbooks based on execution feedback.
- **[Agentic Harness Engineering (AHE)](../agentic-harness/agentic-harness-engineering.md):** Evolving the harness and tools based on observability.
- **Model Fine-tuning (Offline):** Updating the underlying model weights using collected trajectories (less common for real-time adaptation).

## Benefits
- **Domain Specialization:** Agents become more effective in specific codebases or industries.
- **Efficiency:** Reducing redundant discovery and reasoning steps.
- **Self-Improvement:** The system becomes more robust as it learns from its own failures.
