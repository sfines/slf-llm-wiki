# Collaborative Issue Resolution

**Collaborative Issue Resolution** is the process by which a team of agents autonomously analyzes, specifies, implements, and verifies the fix for a software issue.

## The Agyn Methodology
The [Agyn Framework](agyn-framework.md) defines a strict collaborative flow:
1.  **Analysis:** The [Researcher](agyn-role-researcher.md) explores the codebase and identifies the root cause.
2.  **Specification:** The Researcher documents the required changes.
3.  **Implementation:** The [Implementer](agyn-role-implementer.md) writes code and tests in a [Sandbox](agyn-sandbox-environments.md).
4.  **Review:** The [Reviewer](agyn-role-reviewer.md) validates the PR.
5.  **Iteration:** If review fails, the team repeats steps 3-4 until success.
6.  **Merge:** The [Coordinator](agyn-role-coordinator.md) finalizes the resolution.

## Human Parallels
This process is a direct replication of human development methodologies (like Agile or GitFlow) for the [Autonomous Era](../core-concepts/autonomous-agents.md).
