# Model Context Protocol (MCP)

The Model Context Protocol (MCP) is an open standard that enables developers to build secure, two-way connections between their data sources and AI models.

## Role in MAS
MCP provides a [Published Language](context-mapping-for-agents.md) for agents to interact with tools and data sources in a standardized, interoperable way.

## Benefits
- **Interoperability:** Allows agents from different families to use the same tools.
- **Security:** Provides a clear boundary for data and tool access.
- **Extensibility:** Easy to add new data sources to an agentic system.
