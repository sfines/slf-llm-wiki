# ACE Process: Reflection

**Reflection** is the second stage of the [Agentic Context Engineering (ACE)](agentic-context-engineering.md) modular process.

## Role in Context Evolution
The reflection phase analyzes the performance of generated strategies against real-world execution feedback. It identifies what worked, what failed, and *why*.

## Key Activities
- **Feedback Integration:** Consuming "natural execution feedback" (e.g., test results, compiler errors, task success/failure) to evaluate context effectiveness.
- **Root-Cause Attribution:** Determining if a failure was due to the model's base capability or a flaw in the provided instructions/strategies.
- **Strategic Critique:** Analyzing the trade-offs of different generated candidates.

## Preventing Context Collapse
By explicitly reflecting on the value of information before it is integrated, ACE ensures that critical details are not "iteratively rewritten away" over time, a phenomenon known as context collapse.
