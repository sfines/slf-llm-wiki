# Two-Dimensional AI Agent Framework

The Two-Dimensional Framework for AI Agent Design Patterns proposes classifying agent architectures using two orthogonal axes: **Cognitive Function** (what the agent does) and **Execution Topology** (how data flows). 

Proposed by Huang and Zhou (2026), this matrix resolves the ambiguity of previous frameworks that only focused on one dimension, noting that the same structural topology (like Orchestrator-Workers) can implement vastly different cognitive functions (such as Action planning, Collaboration, or Governance monitoring).

## The Matrix
1. **[Cognitive Function Axis](./cognitive-function-axis.md):** 7 categories including Context Engineering, Memory, Reasoning, Action, Reflection, Collaboration, and Governance.
2. **[Execution Topology Axis](./execution-topology-axis.md):** 6 archetypes including Chain, Route, Parallel, Orchestrate, Loop, and Hierarchy.

The resulting 7x6 matrix identifies 27 distinct named patterns (e.g., [Context Triage](./context-triage-pattern.md), [Complexity-Based Routing](./complexity-based-routing-pattern.md), [Blast Radius Control](./blast-radius-control-pattern.md)).
