# Cognitive Function Axis

In the [Two-Dimensional AI Agent Framework](./two-dimensional-agent-framework.md), the **Cognitive Function** axis represents *what* an agent is doing at a given moment—forming a cognitive processing pipeline.

The seven defined categories are:
1. **Context Engineering:** Determining what information enters the agent's working memory (e.g., [Context Triage](./context-triage-pattern.md)).
2. **Memory:** How the agent stores, retrieves, and updates knowledge (e.g., RAG Pipelines, Failure Journals).
3. **Reasoning:** How the agent deliberates and decides (e.g., Chain-of-Thought, [Complexity-Based Routing](./complexity-based-routing-pattern.md)).
4. **Action:** How the agent acts on the world through tools (e.g., Plan-and-Execute).
5. **Reflection:** How the agent evaluates and improves its own outputs (e.g., Generator-Critic).
6. **Collaboration:** How multiple agents coordinate to solve a problem (e.g., Fan-Out/Gather).
7. **Governance:** How the agent is bounded, observed, and controlled (e.g., [Blast Radius Control](./blast-radius-control-pattern.md), Approval Gates).

This axis is orthogonal to the [Execution Topology Axis](./execution-topology-axis.md).
