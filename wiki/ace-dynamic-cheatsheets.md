# Dynamic Cheatsheets

A **Dynamic Cheatsheet** is a core component of the [Agentic Context Engineering (ACE)](agentic-context-engineering.md) framework, acting as a living repository of successful strategies and domain-specific insights.

## Role in Context Evolution
Unlike a static system prompt, a dynamic cheatsheet is updated incrementally based on [Natural Execution Feedback](ace-execution-feedback.md). It serves as the "evolved playbook" that the agent carries across tasks.

## Content Types
- **Successful Reasoning Paths:** Step-by-step examples of how to solve specific types of problems.
- **Error Remediation Rules:** Instructions on how to recover from known failure modes.
- **Tool-Use Best Practices:** Domain-specific guidelines for selecting and parameterized tools.

## Preventing Information Loss
By using [Adaptive Memory](ace-adaptive-memory.md) to manage the cheatsheet, ACE ensures that high-signal information is preserved even as the agent's experience grows, avoiding [Context Collapse](ace-context-collapse.md).
