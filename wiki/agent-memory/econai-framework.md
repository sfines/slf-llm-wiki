# EconAI Framework

The EconAI framework is a novel approach designed to enhance the long-term decision-making capabilities of large language models (LLMs) within economic simulations. By replacing simplistic rule-based agents or computationally prohibitive neural networks with a single cognitive LLM backbone, it provides a comprehensive platform for Agent-Based Modeling (ABM). 

## Core Architecture
EconAI categorizes agents into distinct roles—such as households for microeconomic modeling and firms for macroeconomic dynamics. Crucially, it integrates government policies and financial institutions to create a realistic environment. 

## Key Adaptive Mechanisms
Unlike traditional data-driven models that rely on static predictions, EconAI incorporates continuous adaptive mechanisms:
- **Event Memory Modules**: Managing both short-term market conditions and long-term economic patterns.
- **Dynamic Personas**: Extracting and updating agent preferences and economic beliefs over time.
- **Economic Sentiment Index (ESI)**: Quantifying the agent's confidence and emotional state regarding the broader economy to modulate behaviors organically.

These elements combine to allow agents to seamlessly transition between short-term responsiveness (reacting to sudden market shocks) and long-term strategic planning, absorbing multi-year shifts rather than resetting their logic at every simulation step.
