# Memory Automation Frontiers

**Memory Automation** is the research area focused on building agents that can autonomously manage their own memory lifecycle without human-designed heuristics.

## Vision
In a fully automated system, the agent:
- Decides what to remember and what to forget.
- Organizes its own knowledge base (e.g., self-correcting a [Knowledge Graph](../advanced-retrieval/pseudo-knowledge-graph.md)).
- Optimizes its own retrieval strategies based on performance feedback.

## Relationship to AHE and ACE
Memory automation is a core component of both **[Agentic Harness Engineering (AHE)](../agentic-harness/agentic-harness-engineering.md)** and **[Agentic Context Engineering (ACE)](../agentic-harness/agentic-context-engineering.md)**, as it treats the agent's internal knowledge as an evolving, engineerable asset.
