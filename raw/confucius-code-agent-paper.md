# Confucius Code Agent: Scalable Agent Scaffolding for Real-World Codebases

**Authors:** Sherman Wong, Zhenting Qi, Zhaodong Wang, Nathan Hu, Samuel Lin, Jun Ge, Erwin Gao, Wenlin Chen, Yilun Du, Minlan Yu, Ying Zhang
**Date:** December 2025
**Source:** arXiv:2512.10398
**DOI:** 10.48550/arXiv.2512.10398

## Abstract Summary
The **Confucius Code Agent (CCA)** is designed to operate on large-scale repositories and sustain long-horizon sessions. It is built on the **Confucius SDK**, which balances Agent Experience (AX), User Experience (UX), and Developer Experience (DX). CCA features hierarchical working memory, persistent note-taking for continual learning, and a meta-agent for automated configuration refinement.

## Key Features
- **Confucius SDK:** A platform for structured agent development.
- **Three Core Perspectives:** AX (reasoning), UX (controllability), DX (extensibility).
- **Hierarchical Working Memory:** For long-context reasoning.
- **Persistent Note-Taking:** Enables cross-session continual learning.
- **Meta-Agent Loop:** Automates the build-test-improve cycle for agent configurations.

## Key Results
- Achieved **54.3% Resolve@1** on SWE-Bench-Pro.
- Demonstrates strong performance and scalability on production-level workloads.
