# Agyn: A Multi-Agent System for Team-Based Autonomous Software Engineering

**Authors:** Nikita Benkovich, Vitalii Valkov
**Date:** February 2026
**Source:** arXiv:2602.01465
**DOI:** 10.48550/arXiv.2602.01465

## Abstract Summary
**Agyn** is an open-source platform that models software engineering as an organizational process, replicating the structure of a human engineering team. It assigns specialized agents to roles (coordination, research, implementation, review) and follows a defined development methodology (analysis, specification, PR creation, iterative review) without human intervention.

## Key Features
- **Team-Based MAS:** Replicates human team structures and role separation.
- **Organizational Design:** Focuses on the "process" of engineering rather than just task execution.
- **Isolated Sandboxes:** Provides agents with safe environments for experimentation.
- **Structured Communication:** Enables agents to collaborate following shared methodologies.
- **Zero Human Intervention:** Operates autonomously from issue analysis to PR creation.

## Key Results
- Resolved **72.2%** of tasks on SWE-bench 500.
- Outperformed single-agent baselines using comparable models.
- Demonstrates that organizational design is a powerful paradigm for autonomous SE.
