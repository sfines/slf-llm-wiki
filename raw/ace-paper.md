# Agentic Context Engineering: Evolving Contexts for Self-Improving Language Models

**Authors:** Qizheng Zhang, et al.
**Date:** 2025
**Source:** arXiv:2510.04618
**DOI:** 10.48550/ARXIV.2510.04618

## Abstract Summary
This paper introduces **ACE (Agentic Context Engineering)**, a framework that treats contexts as evolving playbooks. It addresses the issues of "brevity bias" and "context collapse" in LLM applications by using a modular process of generation, reflection, and curation to refine instructions and strategies based on natural execution feedback.

## Key Findings
- Consistently outperforms strong baselines (+10.6% on agents, +8.6% on finance).
- Matches top-ranked production-level agents on AppWorld despite using smaller open-source models.
- Effectively adapts without labeled supervision by leveraging execution feedback.
